# Тестовая панель

Адрес: `admin.html` рядом с `index.html`. Открывать через сайт или локальный
HTTP-сервер, а не как файл: панель загружает HTML игры через fetch.

Панель запускает настоящую игру внутри iframe, меняя только окружение:
GamePush SDK и обычный мост не загружаются, вместо них используется
`admin-sandbox.js`. Все пути сохранения игры получают отдельный ключ
`dog-yard-admin-test-v1`, включая миграцию, автосохранение, сброс и pagehide.
Основное сохранение не копируется и не изменяется. Снимок панели хранится
отдельно под ключом `dog-yard-admin-test-v1-checkpoint`.

## Проверки

- Породы, дворы, друзья и наклейки: выбрать или открыть коллекцию.
- Анимация: автоматическое поведение или заданное состояние, направление,
  пауза, следующий кадр, скорость. В ручном режиме собака стоит на месте.
- Экономика: косточки, энергия, медали, жёлуди, доверие, престиж, уровень двора.
- Прогресс: уровни отдельных карточек, улучшений и дрессировки; счётчики
  достижений. Задания можно подготовить, затем забрать награду обычной кнопкой.
- Мини-игры: принудительный запуск без ожидания таймера. Прогулки используют
  настоящие условия доступа и формулы награды. При необходимости сначала
  выставить энергию, уровень двора и престиж. Завершение вызывает обычное
  начисление награды, поэтому его можно проверить на повторное получение.
- Платные ветки и постоянные покупки: локальные переключатели владения.
  Они не проверяют реальный платёжный процесс и не отправляют покупки.
- Снимок, восстановление, экспорт/импорт тестового JSON, новая тестовая игра.
- Выбор экранов, ширины iframe, живые счётчики, JSON состояния, журнал ошибок.

## Границы

Это открытая диагностическая панель статической клиентской игры, а не
защищённая серверная админка. В ней нет управления аккаунтами других игроков
или доступа к облачным данным. Обычная игра не загружает admin-модули;
дополнительный API создаётся только внутри тестового окружения.

`npm test` проверяет команды, ограничения значений, запрет запуска параллельных
активностей, отделённые снимки и неизменность основных ключей сохранения при
сохранении/сбросе тестовой игры. Внешние SDK и реальные платежи здесь не тестируются.
