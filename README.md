# Собачий дворик (Dog Yard Clicker)

Idle/clicker на чистом HTML5 для [GamePush](https://gamepush.com/). Милая тема про пёсиков и косточки. Без сборки. **Content pack v5 (retention)**.

Папка проекта: `ore-mine-clicker` (локальный сервер на порту 8765).

## Локально

```bash
cd /workspace/ore-mine-clicker
python3 -m http.server 8765 --bind 127.0.0.1
```

Открыть: [http://127.0.0.1:8765](http://127.0.0.1:8765)

## GamePush

1. Панель → **Установить код** → `projectId` / `publicToken` (уже: **30253**).
2. Поле игрока **`save`** (строка/JSON) — уже используется в `js/gp-bridge.js`.
3. Без SDK работает локально (`dog-yard-clicker-v1`, миграция с `ore-mine-clicker-v1`). Save **v5**.

### Продукты (обязательно создать в панели)

| Тег | Тип | Эффект в игре |
|-----|-----|----------------|
| `BONES_PACK_S` | расходник | +2 500 косточек → grant → consume |
| `BONES_PACK_M` | расходник | +25 000 косточек → grant → consume |
| `NO_ADS` | постоянный | `state.noAds`: бонус без видео, sticky скрывается |
| `VIP_TREATS` | постоянный | `state.vipTreats`: +15% ко всем доходам |

Вкладки primary: **Магазин | Дрессировка | Породы | Двор | Ещё** (sheet; Покупки в Ещё).

## Геймплей (v5 retention · hard nerf)

- Клик / idle с **softcap** (@180 / @70, power 0.5); комбо; «Радость»; **энергия** жёстче
- Апгрейды **~1.22–1.35**; mid/late базы ×2–4; early ~5–10 мин ок, потом стена
- **Прогулки** 3–7.5 мин, награды слабее (~×0.55)
- **Этапы двора** 1–6 — пороги ×2–3 + сюжетный хук
- **Ежедневные цели** / квесты — выше таргеты, чуть меньше наград
- События ~10–15 мин, награды ×1.05; сезон — меньше желудей, дороже магазин
- Выставка: порог **2e8 × 2.2^уровень**; медальки +2% + **магазин медалек** (дороже)
- Офлайн: кап тот же, **эффективность** без Будки/Лежанки ~20%
- First prestige цель: **~3–6 ч** engaged; «купить всё за сессию» — невозможно
- **Дрессировка**: цепочка Сит→…→Чемпион; gated shop: Свисток клика / Волонтёры / Автокормушка / Питомник+

### Как попробовать

| Фича | Как |
|------|-----|
| Энергия | Полоска под псом; кликай → падает; «Отдых» или подожди |
| Прогулка | Кнопка «Прогулка» → тир → таймер в фоне → «Забрать» |
| Этапы | Двор / Выставка — прогресс-бар, кнопка открытия этапа |
| Цели дня | Ещё → Квесты (верх блока) |
| Медальки | Выставка после престижа → магазин 🏅 |
| Save | Автосейв v5; старые сейвы мигрируют без вайпа |

Баланс-константы в начале `js/game.js`.
