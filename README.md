# Собачий дворик (Dog Yard Clicker)

Idle/clicker на чистом HTML5 для [GamePush](https://gamepush.com/). Милая тема про пёсиков и косточки. Без сборки. **Content pack v4 + monetization**.

Папка проекта: `ore-mine-clicker` (локальный сервер на порту 8765).

## Локально

```bash
cd /workspace/ore-mine-clicker
python3 -m http.server 8765 --bind 127.0.0.1
```

Открыть: [http://127.0.0.1:8765](http://127.0.0.1:8765)

## GamePush

1. Панель → **Установить код** → `projectId` / `publicToken` (уже: **30253**).
2. Поле игрока **`save`** (строка/JSON) — уже используется в `js/gp-bridge.js`.
3. Без SDK работает локально (`dog-yard-clicker-v1`, миграция с `ore-mine-clicker-v1`).

### Продукты (обязательно создать в панели)

В GamePush → **Products** создайте продукты с **теми же тегами**:

| Тег | Тип | Эффект в игре |
|-----|-----|----------------|
| `BONES_PACK_S` | расходник | +2 500 косточек → grant → consume |
| `BONES_PACK_M` | расходник | +25 000 косточек → grant → consume |
| `NO_ADS` | постоянный | `state.noAds`: бонус без видео, sticky скрывается |
| `VIP_TREATS` | постоянный | `state.vipTreats`: +15% ко всем доходам |

Вкладка в игре: **«Покупки»** / «Магазин GP». Без GP платежи симулируются через `confirm`.

Репозиторий (опционально): добавьте ссылку на свой git remote после `git push`.

## Геймплей (v4)

- Клик / idle, комбо (до x3), буст «Радость» x2 на 10 с
- Апгрейды, предметы, породы, дворы (Солнечный / Вечер / Зима / **Осень**)
- События (ротация + кулдаун): игрушка, Simon-дрессировка, **«Прятки»**, **«Гонка за белкой»**
- **Альбом** — 12 наклеек, наборы с разовой наградой
- **Друзья** — кот / кролик / хомяк (один активный, аватар у пса)
- **Осенний фестиваль** — жёлуди, сезонный магазин (`SEASON_FORCE=true`)
- История: **13 глав**, квесты, достижения, выставка
- Реклама: rewarded (или без видео при NO_ADS); fullscreen иногда после выставки/события
- Вкладки: Магазин | Породы | Друзья | Двор | Альбом | Сезон | Квесты | Достижения | История | Выставка | **Покупки**

### Как попробовать фичи

| Фича | Как |
|------|-----|
| Прятки / Гонка | Кнопка «Событие» когда готова (или дождитесь баннера ~3–5 мин). |
| Альбом | Вкладка «Альбом»; наборы дают награду один раз. |
| Друзья | Вкладка «Друзья» → купить → «Активировать». |
| Сезон | Баннер 🍂 / вкладка «Сезон». |
| Покупки GP | Вкладка «Покупки»; локально — confirm-заглушка. |
| Save | Автосейв в поле `save` + localStorage. |

Баланс-константы в начале `js/game.js` (`BASE_CLICK`, `VIP_INCOME_MULT`, `SEASON_FORCE`, …).
