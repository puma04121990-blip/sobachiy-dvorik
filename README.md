# Собачий дворик (Dog Yard Clicker)

Idle/clicker на чистом HTML5 для [GamePush](https://gamepush.com/). Милая тема про пёсиков и косточки. Без сборки. **Content pack v4**.

Папка проекта: `ore-mine-clicker` (локальный сервер на порту 8765).

## Локально

```bash
cd /workspace/ore-mine-clicker
python3 -m http.server 8765 --bind 127.0.0.1
```

Открыть: [http://127.0.0.1:8765](http://127.0.0.1:8765)

## GamePush

1. Панель → **Установить код** → `projectId` / `publicToken`
2. Вставить в `index.html` (URL SDK) и `js/gp-bridge.js`
3. Поле игрока `save` (строка/JSON)

Без токенов работает локально (`dog-yard-clicker-v1`, миграция с `ore-mine-clicker-v1`, **save v4** с defaults).

## Геймплей (v4)

- Клик / idle, комбо (до x3), буст «Радость» x2 на 10 с
- Апгрейды, предметы, породы, дворы (Солнечный / Вечер / Зима / **Осень**)
- События (ротация + кулдаун): игрушка, Simon-дрессировка, **«Прятки»**, **«Гонка за белкой»**
- **Альбом** — 12 наклеек, наборы с разовой наградой
- **Друзья** — кот / кролик / хомяк (один активный, аватар у пса)
- **Осенний фестиваль** — жёлуди, сезонный магазин (`SEASON_FORCE=true`)
- История: **13 глав**, квесты, достижения, выставка
- Вкладки: Магазин | Породы | Друзья | Двор | Альбом | Сезон | Квесты | Достижения | История | Выставка

### Как попробовать фичи

| Фича | Как |
|------|-----|
| Прятки / Гонка | Кнопка «Событие» когда готова (или дождитесь баннера ~3–5 мин). Тип случайный. |
| Альбом | Вкладка «Альбом»; наклейки с достижений, событий, глав, друзей, сезона. Заберите награду набора. |
| Друзья | Вкладка «Друзья» → купить за косточки → «Активировать». Аватар справа внизу у пса. |
| Сезон | Баннер 🍂 / вкладка «Сезон». Жёлуди капают с кликов; магазин: осенний двор, наклейка, буст. |
| Новые главы | Вкладка «История» — ch8–ch13 по косточкам / друзьям / наклейкам / событиям. |
| Save v4 | Автосейв; старые сейвы мигрируют с пустыми `stickers[]`, `unlockedFriends`, `acorns:0`. |

Баланс-константы в начале `js/game.js` (`SEASON_FORCE`, `ACORN_PER_CLICK`, …).
